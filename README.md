# PokeBrabo — downloads

Este repositório guarda **somente os arquivos de instalação e atualização** do cliente do jogo PokeBrabo.
O código-fonte é privado e não fica aqui.

## Como jogar
1. Baixe o `PokeBrabo-Launcher.exe` da [release mais recente](https://github.com/Dheph/PokeBrabo-releases/releases/latest).
2. Abra o launcher: ele instala o jogo em `%LOCALAPPDATA%\PokeBrabo` e mantém tudo atualizado sozinho.
3. Clique em **Jogar**.

As releases são publicadas automaticamente pelo pipeline do projeto; cada uma contém o `manifest.json`
(com sha256 de cada arquivo) que o launcher usa para verificar o que baixa.
